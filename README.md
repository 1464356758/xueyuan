# 小说平台学院

本仓库是小说生产系统的平台规则知识库。APP选择平台后，AI角色通过 `学院入口.json` 找到对应平台入口，再按角色调用矩阵读取必需资料。

## 证据分层
- `HARD`：平台官方现行制度、合规、签约、推荐、完结等硬规则。违反会带来审核、推荐、账号或版权风险。
- `CURRENT`：当前活动、征文、福利、趋势信号。必须检查有效期，过期后不得继续当作新书硬目标。
- `GUIDE`：平台官方创作课程、品类指南、功能教程。
- `DERIVED`：为AI小说生产系统整理的内部执行规则。它不是平台原文，必须服从HARD层。

## 使用原则
1. 官方来源优先；第三方经验不得覆盖官方规则。
2. 活动必须带快照日期、起止日期和有效状态。
3. 历史规则只能用于理解演进，不得冒充当前门槛。
4. 一本小说立项时，总监应冻结本次使用的学院commit SHA及关键文件SHA，避免后续规则更新污染已立项项目。
5. 番茄资料当前核验日期：2026-09-18。
