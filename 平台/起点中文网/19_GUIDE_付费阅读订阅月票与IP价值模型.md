# GUIDE｜付费阅读、订阅、月票与IP价值模型

## 1. 起点不是单纯免费流量平台
核心价值链包括：新书获取读者→持续追读→VIP订阅→书友互动/月票→长期口碑→精品/IP开发。

## 2. 写作对应
免费期：证明故事值得追；付费期：每个章节继续提供新价值，不能靠重复悬念拖订阅。

## 3. 月票
月票代表核心读者支持并影响榜单/荣誉；福利月票存在更新与互动条件，但AUTO不得为了月票把正文机械拆成水章。

## 4. 精品与荣誉
2026起点作品荣誉页可见“VIP字数满20万、均订大于1万”的万人追捧，以及精品频道、首订过万、日更万字等荣誉实例。它们是荣誉条件/结果信号，不等于签约门槛或所有作品的推荐条件。

## 5. IP
阅文官方强调小说到影视、动漫、游戏、漫画、衍生品的IP链。创作可考虑世界观可视化、角色识别、长线矛盾和跨媒介潜力，但小说订阅可读性仍优先。
