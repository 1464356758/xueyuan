# GUIDE｜题材赛道与IP改编方向

## 1. 题材信号如何使用
平台活动代表“平台正在扶持/征集的方向”，不是永久热门榜。灵感员可用它增加候选权重，但不能仅因为有奖金就选一个自己无法长期写好的题材。

## 2. 2026-09当前长篇强信号
- 玄幻、仙侠、历史：当前有专门长篇征文，强调长期稳定更新与剧情打磨。
- 精品长篇/IP：神启计划长期存在，说明人物成长、世界观、悬念、结构和改编潜力都重要。
- “强设定开局×高密度爽点”：近期改编风向标信号，适合转化为清晰设定 + 高频有效回报。

## 3. 短故事/IP强信号
当前活动可观察到：
- 男/女频脑洞；
- 悬疑惊悚；
- 玄幻仙侠；
- 青春/古言虐恋；
- 历史古代；
- 都市日常；
- 宫斗宅斗；
- 现言/古言甜宠；
- 民国旧影、年代、女性成长；
- 都市现实、青春治愈、非遗、科幻脑洞；
- 西方狼人/吸血鬼/黑手党/西幻等短篇赛道。

## 4. IP改编评估（DERIVED）
灵感裁判对长篇候选增加以下检查，但不作为平台硬门：
- 核心设定是否一句话可传播；
- 主角关系是否有稳定戏剧张力；
- 场景是否有视觉辨识度；
- 高潮是否能形成清晰事件；
- 是否有改编时可压缩的主因果线；
- 是否依赖大量内心独白才能成立；
- 是否具有版权原创性。

## 5. 反同质化
IP回响计划官方明确鼓励跳出同质化、重视真实成长与真诚表达。内部选题禁止只做“热榜标题换皮”。至少必须在世界规则、人物关系、职业/场景、核心矛盾、叙事结构五项中有两项实质新变化。
