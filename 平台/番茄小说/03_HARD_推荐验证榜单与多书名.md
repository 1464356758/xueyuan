# HARD｜推荐验证、榜单与多书名

## 1. 2026推荐验证
番茄2026年2月发布长篇网文推荐验证流程调整通知，2026年7月又发布“推荐验证期规则全指南”。现行机制至少区分推荐评估/推荐验证等环节。

内部原则：
- 不硬编码旧版固定推荐字数；
- 以创作中心当前显示的作品资格、推荐状态和当期官方规则为准；
- “规则合规”不等于“必然有流量”，官方指南也单列“为什么合规但流量仍可能不好”的问题，因此选题、首章、追读、人物与长期内容质量仍需独立优化。

## 2. 当前公开排行榜规则
番茄官网当前榜单说明：
- 作品按分类排榜，按“在读”数据排序；
- 仅展示达到1000在读以上的作品；
- 阅读榜：30万字以上、已签约、未下架、已开始推荐的番茄原创作品；
- 新书榜：30万字以下、已签约、未下架、已开始推荐且未断更的番茄原创作品；完结作品需满足榜单所列完结时间条件；
- 榜单通常每日更新上一日数据。

注意：榜单准入条件不是签约资格，也不是推荐资格，三者不可混淆。

## 3. 多书名实验
番茄官方持续提供多书名实验相关教程。内部用途：当作品满足平台开放条件时，可以用平台功能测试标题表现，而不是在正文里频繁改定位。

标题候选应做到：
- 一眼识别主要类型/核心冲突；
- 体现独特设定或利益点；
- 不虚假承诺正文没有的内容；
- 避免多个标题只是同义词排列；
- 不借热点作品名制造混淆或侵权风险。

## 4. AI优化目标
推荐阶段真正可控的是：
- 首章进入事件速度；
- 核心设定可理解度；
- 主角目标与风险清晰度；
- 每章有效变化和章末继续阅读动机；
- 人物关系升级；
- 承诺兑现速度；
- 长线冲突有升级空间；
- 更新稳定性。
不得把“刷量”当推荐优化手段。
