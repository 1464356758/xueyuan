# HARD｜签约、实名、合同与收益制度

核验日期：2026-09-18。合同与创作中心实时页面优先于本摘要。

## 1. 当前签约流程框架
番茄2026官方签约FAQ与签约流程说明包含：获得签约资格 → 安全审核 → 签约评估 → 合同审核/填写 → 手机验证电子签约 → 合同生成 → 签约完成。

官方2026-05 FAQ给出的预计时效：
- 安全审核：约1–3天；
- 签约评估：约1–5个工作日；
- 合同审核：约1–3个工作日。
这是预计时效，不等于保证完成时间。

## 2. 实名与收款信息
- 签约手机号、银行卡实名人需与作家账号实名一致；
- 官方建议使用非虚拟手机号，避免影响签约；
- 银行卡信息必须准确。官方FAQ说明，在银行卡号正确的情况下，找不到精确支行通常不影响稿费打款/提现，但仍应以当前页面要求填写；
- 未成年人签约存在单独问题与流程，不能由AI自行假设成年人规则直接套用。

## 3. 不硬编码旧门槛
历史官方页面曾出现“达到一定字数获得签约机会”等产品阶段规则，但2026系统不得把旧的固定字数说法当作普遍现行资格。是否获得签约入口，以当前创作中心、作品状态和最新官方规则为准。

## 4. 收益类型
官方2026稿费福利说明覆盖：
- 听读收益；
- 互动收益；
- 集团渠道/集团版权/渠道/版权等收益；
- 全勤奖；
- 星火计划及其他福利。
具体计算口径、资格、周期以当期官方页面和合同为准。

官方福利页对签约类型的高层信息包括：
- 独家分成签约：按合同约定参与站内外渠道等收益分配；
- 优质保底签约：面向符合条件作者/作品，保底或买断标准依合同与邀约；
- 读者礼物等互动收益存在作者分成规则；
- 短剧、动态漫、影视、音频、出版、漫画、游戏等版权开发收益依具体合同。

## 5. 系统内部执行要求
- 灵感员不承诺“必签约”“必保底”。
- 总监不得根据旧教程虚构签约门槛。
- 任何收益数字若来自活动，必须记录活动名称和有效期。
- 任何合同分成判断必须加“以作者实际合同为准”。
- 不为了满足猜测中的字数门槛而灌水。
