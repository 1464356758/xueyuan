# 番茄小说｜平台总览与AI调用说明

核验日期：2026-09-18。

## 一、平台定位
番茄小说具有长篇原创、短故事、版权改编、短剧/漫剧等多层内容生态。对本系统最重要的不是机械追热点，而是同时满足：内容合规、原创可持续、前期吸引力、长期更新能力、读者追读与IP潜力。

## 二、AI读规则的顺序
1. 先读 `01_HARD`、`08_HARD`，确认题材和表达没有平台风险。
2. 灵感/选题阶段再读 `05_CURRENT`、`07_GUIDE`，利用当期官方活动和赛道信号。
3. 总监立项时读 `02/03/04_HARD`，避免签约、推荐、完结逻辑错误。
4. 写作阶段读 `06_GUIDE` 与 `09_DERIVED`，把官方创作建议转成章节动作。
5. 活动到期后自动降级为历史资料，不得继续当作“当前扶持”。

## 三、2026-09-18的关键平台信号
- 官方正在持续治理低质、批量量产、内容水化/堆砌、刷量等行为。
- 推荐采用“推荐评估/推荐验证”等现行机制，旧教程中的固定字数门槛不能直接当2026现行规则。
- 当前官方活动同时覆盖高质量长篇、玄幻/仙侠/历史、短故事IP、女性成长、现实表达、科幻脑洞等方向。
- 当前作家专区还出现“强设定开局×高密度爽点”的改编风向标，说明“快速建立卖点 + 持续兑现”是值得关注的编辑信号，但它不是所有题材都必须爽文化。
- 神启计划强调完整成长弧、鲜明配角、原创世界观、连续悬念、张弛节奏和伏笔回收，说明长期结构质量仍是精品方向核心。

## 四、禁止错误简化
- 不得把“爽点密度”理解成无因果打脸堆砌。
- 不得把活动题材当成平台唯一流量题材。
- 不得把历史的2万字签约、8万字/10万字推荐说法写成2026硬规则。
- 不得为了“AI效率”批量制造同结构、同语气、同桥段作品。
